Prompt engineering was about finding magic words. Context engineering is about something more boring and more important: deciding *what information* the model sees at each step, in what shape, and at what cost.

## The context window is a budget, not a bucket

Every token you put in the window competes with every other token for the model's attention. Dumping ten retrieved documents into the prompt "just in case" doesn't make answers better — it buries the two paragraphs that mattered. Treat context like a budget:

- **Relevance beats volume.** Five tightly relevant chunks outperform fifty loosely relevant ones.
- **Position matters.** Models attend most reliably to the start and end of the window. Put instructions early and the freshest facts late.
- **Stale context is negative context.** An outdated file snippet or a superseded decision actively misleads the model.

## The main levers

In practice, context engineering comes down to a handful of moves:

**Retrieval** — fetch only what the current step needs. Chunk sensibly, rerank, and cap the number of results. A RAG system that can say "nothing relevant found" is healthier than one that always pads the window.

**Compaction** — when history grows, summarize it. Keep decisions and constraints; drop the play-by-play. An agent that carries a two-line summary of thirty turns behaves better than one dragging the full transcript.

**Structured state** — instead of hoping the model remembers, hand it explicit state: a task list, a scratchpad file, the current plan. External memory beats window memory.

**Tool results hygiene** — tool outputs are the fastest-growing part of agent context. Truncate aggressively, return structured data instead of raw dumps, and strip what the next step won't use.

## A useful test

Before every piece of context, ask: *if I deleted this, would the model's next action change?* If the answer is no, it's not context — it's noise you're paying for, in dollars and in accuracy.

Prompts are still worth polishing. But when a modern LLM app misbehaves, look at what was in the window first. Nine times out of ten, the prompt was fine and the context was wrong.
